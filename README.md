# Neon Pulse

A small, offline-friendly arcade survival game built with HTML, CSS, and JavaScript.

## Run as a Linux desktop app

Install the dependencies and launch the desktop window:

```sh
npm install
npm start
```

To build distributable Linux packages:

```sh
npm run dist
```

This creates AppImage and Debian `.deb` packages in `dist/`. You can also open `index.html` directly in Firefox or Chromium without installing anything.

## Controls

- Pointer mode: move the mouse or touch to steer.
- Keyboard mode: move with WASD or the arrow keys.
- Press `P` or `Esc` to pause or resume.

Your best score is saved in the browser on this device.
